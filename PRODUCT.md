## Stack
This project presence is a static HTML/CSS/JavaScript site with no build step. The opening retains the user's three.js 0.169.0 glass template. The ShelfWise application itself uses React/React Native, Expo Router, Node.js, Express, Sequelize, PostgreSQL, and S3.

## Users and Purpose
Academic and industry capstone reviewers need a concise project overview, a working application link, team biographies and contacts, and a quick user tutorial. This site supports pre-demo review and follow-up.

## Product Truth
ShelfWise connects retail layouts to product information in an interactive map. Managers create maps, employees maintain store information, and shoppers use visual search and locations. This is a University of Utah senior capstone by Will Black, Conner Francis, Bradley Lund, and Yi Yang. The supplied design document is dated February 24, 2026; descriptions of advanced features there are plans, not proof of deployment.

## Operating Context
The supplied application URL is https://shelfwise-nxbo.onrender.com/. The guest workflow was checked in-browser: Map → Search stores → select a pin → Open store map → Search products, groups, or regions → choose a product → product location. List requires sign-in. No administrative changes were made.
